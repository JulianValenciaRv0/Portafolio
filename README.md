# Portfolio — Julian Andres Valencia Rojas

Portafolio profesional de una página para presentar el perfil, conocimientos, proyectos, formación y datos de contacto de Julian Andres Valencia Rojas, Desarrollador de Software Junior.

## Tecnologías

- HTML semántico
- CSS responsive con variables de diseño
- JavaScript vanilla

## Características

- Diseño adaptable a móvil, tablet y escritorio.
- Navegación interna accesible con menú móvil.
- Información personal, habilidades, formación y proyectos centralizados en `js/config.js`.
- Secciones de proyectos renderizadas desde configuración.
- Accesibilidad con foco visible, enlace para saltar al contenido y preferencia de movimiento reducido.
- Metadatos básicos para buscadores y compartir.
- Preparado para GitHub Pages, sin dependencias de compilación.

## Ejecutar localmente

Abre `index.html` en un navegador o sirve la carpeta con cualquier servidor estático. Por ejemplo, desde la raíz del proyecto:

```sh
python -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Personalización

Edita `js/config.js` para actualizar descripción, enlaces sociales, habilidades, proyectos y estado de formación. Las imágenes de proyectos pueden añadirse a `assets/images/` y asociarse desde ese archivo. Completa los campos identificados con `[AGREGAR ...]` antes de compartir el portafolio.

## Despliegue en GitHub Pages

En GitHub, abre **Settings → Pages**, selecciona la rama `main` y la carpeta raíz (`/`), y guarda. GitHub Pages publicará el sitio desde `index.html`.
